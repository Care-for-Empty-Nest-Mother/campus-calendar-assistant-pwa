# 校历小助手 iOS 使用说明

> 适用设备：iPhone、iPad  
> 适用方式：Safari + PWA + “快捷指令”  
> 当前版本：网页端 1.6、课表提取快捷指令 v9、系统日历同步快捷指令 v2.2  
> 不需要 Mac、不需要 Apple Developer 付费账号、不需要上架 App Store。

## 1. 使用前先了解

iOS 不像 Android APK 一样允许网页直接读取其他应用或任意跨站页面，因此本应用使用两条系统授权通道：

| 要完成的事情 | iOS 使用方式 |
|---|---|
| 把校历小助手放到桌面 | Safari → 分享 → 添加到主屏幕 |
| 从教务系统提取课表 | Safari 分享菜单 → “校历小助手·提取课表 v9” |
| 把日程写入系统日历 | 网页按钮 → “同步系统日历 v2.2” |
| 课前提醒和考试提醒 | 由写入后的系统日历负责 |
| 待办清单 | 作为独立类别同步到系统日历 |
| 离线查看校历、课表和作息 | PWA 缓存 + 浏览器本地数据 |
| Safari 已导入数据迁移到主屏幕版 | 网页“复制课表到主屏幕版” → 主屏幕版“从 Safari 恢复课表” |

第一次使用需要完成两项安装：

1. **提取课表快捷指令 v9**：用于从教务系统读取课表。
2. **系统日历同步快捷指令 v2.2**：用于把课表、考试、上课提醒和待办写入 iPhone/iPad 日历。

安装完成后，日常使用通常只需要点一两次按钮。

## 2. 打开在线版并添加到主屏幕

### 2.1 在线地址

用 Safari 打开：

```text
https://care-for-empty-nest-mother.github.io/campus-calendar-assistant-pwa/
```

不要在微信内置浏览器或普通 App 内打开，必须使用 **Safari**，因为“添加到主屏幕”和分享菜单依赖 Safari。

### 2.2 添加到主屏幕

1. 在 Safari 页面底部点击“分享”按钮；
2. 向下找到“添加到主屏幕”；
3. 名称可以保持“校历小助手”；
4. 点击“添加”；
5. 返回桌面，打开刚添加的图标。

以后可以从桌面图标以独立窗口方式打开，不用每次输入网址。

### 2.3 已在 Safari 导入课表，主屏幕版却显示空白

这是 iOS 的存储隔离机制：**Safari 标签页**和“添加到主屏幕”后的独立 Web App，即使网址相同，也会使用两套彼此独立的数据空间。因此 Safari 中已经导入的课表不会自动出现在主屏幕版中。

修复版已经内置跨页面迁移，只需再点两次：

1. 回到 Safari 的校历小助手，进入“课表”；
2. 看到“让主屏幕版显示已导入课表”后，点 **复制课表到主屏幕版**；
3. 返回桌面，打开主屏幕版“校历小助手”；
4. 打开时如果没有自动恢复，点 **从 Safari 恢复课表** 即可。

主屏幕版恢复成功后，以后打开都会直接显示课表。恢复内容不只包括课表，还会一起带入考试、待办、校区设置、主题设置和尚未处理的快捷指令结果。

#### 为什么不能自动同步

iOS 不会让 Safari 标签页和主屏幕 Web App 直接共享 `localStorage` 或 IndexedDB。即使网址、域名和 Service Worker 完全相同，也会使用不同的数据容器。因此本应用采用“用户复制 + 主屏幕恢复”的最小迁移流程，不尝试绕过系统隐私边界。

#### 如果没有看到迁移按钮

1. 用 Safari 打开带更新参数的地址：
   `https://care-for-empty-nest-mother.github.io/campus-calendar-assistant-pwa/?v=ios-transfer-20260916`
2. 进入 **课表**，向下查看“让主屏幕版显示已导入课表”；
3. 点击 **复制课表到主屏幕版**；
4. 完全关闭主屏幕版，再重新打开；
5. 若仍显示空课表，点击 **从 Safari 恢复课表**；
6. 如果系统提示剪贴板读取失败，长按页面中的文本框粘贴刚才复制的数据，再点“解析粘贴内容”。

不需要重新安装课表提取快捷指令或系统日历同步快捷指令。

### 2.4 首次打开建议

- 允许页面保存本地数据；
- 如果页面提示需要读取剪贴板，先允许；也可以在出现提示后手动点“读取剪贴板”；
- 如果 Safari 提示“允许访问”，选择允许当前网站访问；
- 不要清理 Safari 网站数据，否则课表、设置和待办可能被删除。

## 3. 安装课表提取快捷指令 v9

### 3.1 推荐入口

在“校历小助手 → 课表 → 教务系统”区域点击：

**一键安装快捷指令**

也可以直接打开安装页：

```text
https://care-for-empty-nest-mother.github.io/campus-calendar-assistant-pwa/install-ios.html
```

### 3.2 下载到“文件”App

1. 点击“一键下载快捷指令”或“一键安装快捷指令”；
2. 系统面板出现后选择 **存储到文件**；
3. 打开 iPhone/iPad 的 **文件** App；
4. 进入 **下载** 文件夹；
5. 找到：

```text
extract-course-v9.shortcut
```

6. 点击该文件；
7. 选择 **添加快捷指令**；
8. 如果之前安装过旧版同名快捷指令，选择替换或删除旧版后再添加。

### 3.3 开启运行脚本权限

第一次运行提取快捷指令前：

1. 打开系统 **设置**；
2. 进入 **快捷指令**；
3. 找到 **允许运行脚本**；
4. 打开该开关。

如果找不到“允许运行脚本”，先打开一次快捷指令 App，或先创建/运行一个快捷指令后再次查看。

## 4. 提取教务系统课表

### 4.1 先打开正确页面

在 Safari 中打开教务系统登录页：

```text
https://yjsjyjxgl.xsyu.edu.cn/gmis/student/default/index
```

如果学校系统自动跳转到 HTTP 地址，按 Safari 提示继续访问即可。

登录后依次确认：

1. 已进入学生端；
2. 已打开“学生课表查询”或“我的课表”；
3. 页面上的课表表格已经完整显示；
4. 不要停留在登录页、首页或空白 iframe 页面。

### 4.2 运行提取快捷指令

1. 在课表表格完整显示的页面，点击 Safari 顶部的 **分享** 按钮；
2. 在分享面板中找到：

```text
校历小助手·提取课表 v9
```

3. 点击运行；
4. 首次运行时如果提示脚本权限，回到“设置 → 快捷指令”开启“允许运行脚本”；
5. 快捷指令会读取当前页面和一层直接 Frame；
6. 提取完成后会自动打开校历小助手的“快捷指令提取结果”页面。

### 4.3 在结果页完成导入

返回校历小助手后：

1. 页面会自动尝试读取系统剪贴板；
2. 如果自动读取成功，会显示识别结果；
3. 如果没有自动读取，点击：

**读取剪贴板中的提取结果**

4. 如果剪贴板仍不可用，在文本框中长按粘贴，再点“解析粘贴内容”；
5. 核对课程名称、星期、节次、周次、教室和教师；
6. 选择要导入的课程；
7. 选择“替换”或“追加”；
8. 确认导入。

导入成功后，课表页面会显示课程格子，并自动使用当前选择的校区作息时间。

### 4.4 提取失败的判断

如果显示“未从内容中识别出课程”：

- 确认当前页面就是“学生课表查询”；
- 确认表格已经加载完成，不要刚打开就立即分享；
- 确认使用的是最新版 v9，不要继续使用 v4/v5/v7；
- 确认“设置 → 快捷指令 → 允许运行脚本”已开启；
- 回到 Safari 重新打开课表页，再运行一次分享快捷指令；
- 如果仍失败，使用“手动粘贴”或“复制提取脚本”的兜底入口。

## 5. 查看和调整课表

在“课表”页面可以使用：

- **雁塔校区 / 鄠邑校区**：切换作息时间，课表格子保持不变；
- **上一周 / 下一周**：查看不同教学周；
- **今日课程**：显示当天课程；
- **明日课程**：横向滚动查看第二天的课程；
- **上课地点**：教学楼、班级号和教室会显示在课程中；
- **JSON 导入/导出**：备份或迁移课表数据。

如果课表没有更新：

1. 下拉刷新页面；
2. 关闭桌面图标后重新打开；
3. 用带新的 `?v=` 参数的链接打开一次；
4. 检查是否仍在查看旧教学周。

## 6. 安装系统日历同步快捷指令 v2.2

### 6.1 推荐入口

打开：

```text
https://care-for-empty-nest-mother.github.io/campus-calendar-assistant-pwa/install-calendar.html?v=v22
```

也可以在校历小助手的“考试”页面底部点击：

**首次使用 / 升级后：下载并安装“同步系统日历 v2.2”快捷指令**

### 6.2 导入步骤

1. 点击 **一键下载快捷指令**；
2. 选择 **存储到文件**；
3. 打开“文件”App → **下载**；
4. 点击：

```text
calendar-sync-v2.2.shortcut
```

5. 选择 **添加快捷指令**；
6. 安装完成后，Shortcuts 列表中应该能看到：

```text
calendar-sync-v2.2
```

### 6.3 首次运行授权

第一次同步时：

1. 系统会询问是否允许访问日历；
2. 选择允许；
3. 如果提示允许删除或修改日历事件，也选择允许；
4. 之后不需要每次重复授权。

如果拒绝过权限，可以到：

```text
设置 → 隐私与安全性 → 日历 → 快捷指令
```

重新打开权限。

## 7. 同步课表、考试、提醒和待办到系统日历

### 7.1 进入同步区域

打开校历小助手的 **考试** 页面，找到：

**系统日历提醒**

### 7.2 选择同步内容

可以分别勾选：

- 课表；
- 考试；
- 上课提醒；
- 待办清单。

它们可以单独同步，也可以一起同步。不同类别互不影响。

### 7.3 选择日期范围

设置：

- 同步开始日期；
- 同步结束日期。

建议第一次先选择一个较短范围，例如本周到下周，确认写入正常后再扩展到整个学期。

### 7.4 开始同步

点击：

**同步所选到 iPhone / iPad 日历**

网页会：

1. 根据当前课表、考试、提醒和待办生成结构化数据；
2. 把数据复制到系统剪贴板；
3. 自动打开 `calendar-sync-v2.2`；
4. 快捷指令先移除同一类别、同一日期范围内由本助手写入的旧日程；
5. 再批量写入新的日程；
6. v2.2 已关闭逐条添加确认窗口，正常情况下不会再要求为每门课手动点击“添加”。

同步完成后，打开系统“日历”App，在对应日期查看课程、考试、提醒和待办事件。

### 7.5 为什么需要先清除再写入

如果同一日期范围重复同步，旧日程可能与新日程重复。v2.2 会用应用标记和日期范围筛选旧事件，只清除本助手写入的同类别事件，不会删除用户自己创建的其他日历事项。

## 8. 通知与提醒

iOS 端的提醒由系统日历事件负责：

| 类型 | 行为 |
|---|---|
| 课程 | 按课程时间写入，带课前提醒 |
| 考试 | 写入考试日期，带考试提醒 |
| 上课提醒 | 作为独立全天或提示事项写入 |
| 待办清单 | 按截止日期写入提醒 |

如果日历中已有事件但没有弹提醒，检查：

1. 系统“设置 → 通知 → 日历”是否允许通知；
2. 对应日历是否开启了提醒；
3. 是否把事件写到了非默认日历；
4. 日期范围是否正确；
5. 快捷指令是否已经获得日历权限。

iOS 普通 PWA 不能像 Android APK 一样在后台直接发送本地通知，因此系统日历是 iOS 的主提醒通道。

## 9. 离线使用

PWA 首次打开后，会缓存应用外壳。离线状态下一般可以：

- 查看校历；
- 查看课表；
- 查看作息与校车信息；
- 查看已保存的考试和待办；
- 查看已经写入本地存储的数据。

离线状态下不能：

- 登录教务系统；
- 提取新的课表；
- 访问需要网络的校方页面；
- 获取新的节假日或官网数据。

## 10. 数据备份与恢复

建议定期在“课表”页面执行：

**导出当前课表 JSON**

导出的 JSON 可以保存到“文件”App、iCloud Drive 或其他安全位置。

需要恢复时：

1. 打开校历小助手；
2. 进入“课表”；
3. 点击“导入 JSON 文件”；
4. 选择之前导出的 JSON；
5. 核对课程后确认导入。

注意区分两种数据操作：

| 操作 | 用途 | 数据范围 |
|---|---|---|
| 复制课表到主屏幕版 / 从 Safari 恢复课表 | 迁移 Safari 与主屏幕版之间的数据 | 课程、考试、待办、设置、待处理结果 |
| 导出当前课表 JSON / 导入 JSON 文件 | 长期备份、换设备或防误删 | 课表 JSON，建议定期保存 |

清理 Safari 网站数据、删除主屏幕图标、重装浏览器或更换设备可能导致当前容器的本地数据丢失。重要数据请保留 JSON 备份。

## 12. 常见问题速查

| 问题 | 原因 | 处理方式 |
|---|---|---|
| 显示“无效 URL” | 使用了旧版 `shortcuts://import-shortcut` 安装方式 | 改用当前安装页的 Blob 下载方式 |
| 打开 `.shortcut` 却是 HTML | 缓存或下载回退到了网页 | 从安装页重新下载，确认文件名以 `.shortcut` 结尾 |
| `Can't find variable: HTML_RX` | 使用了旧版提取脚本 | 删除旧快捷指令，重新安装 v9 |
| 分享菜单找不到提取快捷指令 | 快捷指令未安装或未注册为网页共享动作 | 重新安装 v9，确认用 Safari 分享 |
| 提取后没有课表 | 当前不是课表页，或表格尚未加载 | 进入“学生课表查询”，等待表格显示后重新运行 |
| 提示剪贴板为空 | Safari 剪贴板权限或上下文限制 | 点击“读取剪贴板”，或手动长按粘贴 |
| 同步时提示找不到快捷指令 | 快捷指令名称与网页启动名不一致 | 重新安装 `calendar-sync-v2.2` |
| 提示“第 0 项” | 使用了旧版 v2.1 | 改用 v2.2 |
| 每门课都要手动点“添加” | 旧版快捷指令没有关闭添加窗口 | 重新安装 v2.2 |
| 日历没有出现新课程 | 日历权限、日期范围或类别的选择不正确 | 检查权限，重新选择范围和类别同步一次 |
| 同步后出现重复课程 | 旧事件未清除或重复运行 | 使用 v2.2 的同类别、同日期范围清除后写入 |
| 桌面图标不更新 | Safari 或 PWA 缓存 | 关闭后重开，使用带 `?v=` 的地址刷新 |
| Safari 已导入，主屏幕版仍显示“尚未导入课表” | iOS 隔离 Safari 标签页与主屏幕 Web App 的存储 | 在 Safari 点“复制课表到主屏幕版”，再打开主屏幕版点“从 Safari 恢复课表” |
| 复制后主屏幕版没有自动恢复 | iOS 可能要求用户点击或允许读取剪贴板 | 点“从 Safari 恢复课表”；失败时在文本框长按粘贴并点“解析粘贴内容” |
| 页面没有显示“复制课表到主屏幕版” | 可能仍加载旧版页面或不在 iOS Safari | 使用带 `?v=ios-transfer-20260916` 的地址重新打开，并在 Safari 中进入课表页 |

## 13. 最短操作清单

第一次使用：

1. Safari 打开在线地址；
2. 分享 → 添加到主屏幕；
3. 课表页安装提取快捷指令 v9；
4. 设置 → 快捷指令 → 允许运行脚本；
5. 登录教务系统并打开“学生课表查询”；
6. Safari 分享 → 校历小助手·提取课表 v9；
7. 回校历小助手核对并导入课表；
   - 若使用主屏幕版，在 Safari 课表页点“复制课表到主屏幕版”，再到主屏幕版点“从 Safari 恢复课表”；
8. 安装 `calendar-sync-v2.2`；
9. 进入考试页，勾选同步内容并选择日期范围；
10. 点“同步所选到 iPhone / iPad 日历”，首次允许日历权限。

以后日常使用：

1. 桌面打开校历小助手；
2. 需要更新课表时，重新运行提取快捷指令 v9；
3. 需要同步系统日历时，进入考试页选择范围后点击同步。
